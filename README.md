# Intel Website Localization — Project 3

Project 3 extends the Intel sustainability timeline with localization, RTL support, Bootstrap, responsive design, accessibility improvements, a newsletter form, and interactive components.

## Project 3 features

- Original nine-card Intel timeline retained
- RTL/LTR layout support
- English and Arabic direction preview controls
- Automatic language-change detection with JavaScript
- Bootstrap responsive three-column section
- Icons and consistent Learn More buttons
- Accessible newsletter form with local-only demo validation
- Bootstrap accordion LevelUp
- Descriptive alt text, keyboard focus styles, skip link, labels, and reduced-motion support
- Responsive mobile layout

The milestone images are reused directly from the completed Project 2 repository.
