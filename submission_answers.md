## 2. Reflection: Probabilistic AI
Before this project, I knew that AI could sometimes give different answers, but I did not fully think about why the same prompt could produce different results. While working with AI on web development, I have seen similar prompts produce different code structures, design ideas, or explanations. At first, that could be confusing because I expected one exact answer. Now I understand that AI is probabilistic, meaning it generates responses based on likely patterns rather than always following one fixed output. Knowing this makes me more careful when using AI. I test the code, compare the result with the project requirements, and make changes instead of assuming the first answer is automatically correct.

## 3. Interview Plan: “How do you approach building accessible websites?”
I would explain that I think about accessibility throughout the development process instead of waiting until the end. I start with semantic HTML and a clear heading and section structure. I add descriptive alt text to images and make sure form inputs have proper labels and instructions. I also check color contrast, keyboard navigation, focus states, and responsive behavior. After building the page, I use tools such as Lighthouse to identify accessibility issues, then fix and retest them. My goal is to make the website usable for as many people as possible across different devices and ways of interacting with the page.
